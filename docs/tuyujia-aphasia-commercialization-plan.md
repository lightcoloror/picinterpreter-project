# 图语家成人失语商业化运营计划

Last updated: 2026-06-08

本文档记录图语家当前更贴合实际的商业化判断。

核心校正：

> 图语家的主战场不是学校特殊教育里的自闭症儿童 AAC，而是成人失语、卒中后沟通障碍、康复照护沟通和家庭照护场景。

因此，商业化对象、试点渠道、产品包装和定价都应围绕成人失语与康复照护重新设计。

相关参考：

- [商业 AAC 商业模式对照](commercial-aac-business-model-benchmark.md)

## 1. 定位

### 1.1 一句话定位

图语家是一个面向中文成人失语患者、卒中后沟通障碍患者及其家属/照护者的辅助沟通系统，在成熟 AAC 板系统基础上，提供中文成人照护场景词库、图片沟通、照护者协作、文本/语音到图片、图片到自然句子的能力。

### 1.2 商业化不是卖什么

图语家短期不应把自己定位为：

- 面向自闭症儿童的泛 AAC 教育 App
- 学校特殊教育班级管理软件
- 单纯卖 App 订阅的消费 SaaS
- 直接替代言语治疗的医疗产品
- 需要马上申请医保/医疗器械资质的 SGD 设备厂商

这些方向不是永远不能做，而是不适合作为当前主线。

### 1.3 商业化实际卖什么

更现实的付费价值是：

- 帮康复场景快速建立可用的失语沟通板
- 帮家属和照护者把患者的基本需求表达跑通
- 帮治疗师/康复老师降低 AAC 初始配置和教学成本
- 帮机构形成可复用的成人失语沟通模板、打印版和数字版
- 提供 AI 辅助的句子生成、词图匹配、个人图片库和多照护者协作
- 提供部署、培训、定制词库、打印沟通册和持续支持

简化说：

> 软件是入口，真正的收费点是让成人失语 AAC 在真实家庭、病房、康复机构里用起来。

## 2. 目标人群与付费方

### 2.1 使用者与付费者不是同一个人

| 角色 | 是否直接使用 | 是否可能付费 | 关键诉求 |
|---|---|---|---|
| 失语患者 | 是 | 通常不是 | 能表达疼痛、厕所、吃喝、情绪、求助、选择 |
| 家属 / 照护者 | 是 | 是 | 降低猜测成本，减少焦虑，能快速知道患者想说什么 |
| 言语治疗师 | 是 | 个人付费能力有限 | 有好用工具辅助评估、训练、家庭作业和沟通板配置 |
| 康复治疗师 / 作业治疗师 | 间接使用 | 个人付费能力有限 | 在训练和护理中快速理解患者需求 |
| 康复医院 / 康复科 / 神经内科 | 机构使用 | 是 | 提升服务质量，减少护患沟通成本，形成特色项目 |
| 居家康复 / 护理 / 养老康复机构 | 机构使用 | 是 | 提升照护效率，减少误解和投诉 |
| 医学院 / 康复学院老师 | 研究/教学使用 | 课题经费可能 | 课题、大创、毕业设计、临床反馈闭环 |
| 残联 / 公益基金会 / 社区康复项目 | 间接推广 | 项目采购可能 | 公益覆盖、低成本工具、可复制服务包 |

### 2.2 优先级

| 优先级 | 对象 | 原因 |
|---|---|---|
| P0 | 康复医院、综合医院康复科、神经内科卒中中心 | 失语患者集中，治疗师和家属同时在场，反馈质量最高 |
| P0 | 言语治疗师、康复治疗师、作业治疗师 | 直接知道场景是否真实，能判断词库是否可用 |
| P1 | 居家康复机构、护理站、养老康复机构 | 成人照护沟通需求强，适合场景化沟通板 |
| P1 | 卒中/失语患者家属 | 真正日常使用者，但获客难，最好通过治疗师触达 |
| P2 | 康复治疗学、听力与言语康复学、护理学、医学信息工程老师 | 适合课题、大创、毕业设计、临床反馈合作 |
| P2 | 残联、公益基金会、社区康复项目 | 适合公益试点和采购，不适合作为第一商业闭环 |
| 低优先级 | 普通学校、儿童自闭症机构 | 与当前成人失语定位不完全一致，暂不作为主渠道 |

## 3. 产品包装

### 3.1 免费基础版

免费基础版必须能完成基本沟通，不能因为付费失败让患者失去表达能力。

建议免费保留：

- 本地基础沟通板
- 成人失语核心场景板
- 基础图片表达
- 基础 TTS
- 打印版/离线版沟通板
- 自托管能力
- 基础个人化编辑

原则：

> 基本沟通权不应被订阅状态绑架。

### 3.2 家庭增强版

面向家属和照护者，不是卖复杂功能，而是卖安心和省事。

可收费能力：

- 云备份
- 多设备同步
- 多照护者协作
- 患者个人图片库同步
- AI 句子生成额度
- 语音/文字转图片额度
- 误选/错图反馈记录
- 家庭使用报告

### 3.3 治疗师版

面向言语治疗师、康复治疗师、作业治疗师。

可收费能力：

- 多患者档案
- 成人失语模板库
- 快速生成个性化沟通板
- 训练记录和反馈导出
- 打印版沟通册导出
- 家属家庭作业模板
- 词图匹配纠错记录
- 案例复用和匿名模板沉淀

### 3.4 机构版

面向康复科、康复医院、护理机构、养老康复机构。

可收费能力：

- 机构账号
- 多治疗师/多患者管理
- 病区/科室通用沟通板模板
- 护理场景板
- 医疗/康复/生活照护板
- 打印沟通册批量生成
- 培训材料
- 数据备份与权限管理
- 私有化部署或本地部署
- 技术支持和定期更新

### 3.5 定制服务

这是最可能产生早期现金流的部分。

可交付：

- 为某位患者定制沟通板
- 为某个科室定制病房沟通板
- 为康复机构定制成人失语模板
- 为家庭制作打印沟通册
- 为机构培训照护者和治疗师
- 私有化部署
- 数据迁移和备份
- 本地化图片库和词库调整

## 4. 定价建议

以下是方向性定价，不是最终价格。真实价格应通过试点验证。

| 产品/服务 | 对象 | 建议价格 |
|---|---|---|
| 免费基础版 | 患者家庭、开源用户 | 免费 |
| 家庭云服务 | 家属 | ¥19-29/月，或 ¥199-299/年 |
| 家庭 AI 增强版 | 需要 AI 句子生成、同步、个人图片库的家庭 | ¥49-69/月，或 ¥499-699/年 |
| 治疗师个人版 | 言语治疗师、康复治疗师 | ¥99-199/月 |
| 机构基础版 | 小型康复机构、护理机构 | ¥3000-6000/年 |
| 机构标准版 | 康复科、康复医院、较大机构 | ¥6000-12000/年 |
| 3 个月试点包 | 科室、机构、课题组 | ¥1000-5000/3个月 |
| 定制沟通板/打印册 | 单个家庭或患者 | ¥300-1500/次 |
| 科室/机构模板定制 | 康复科、护理机构 | ¥3000-20000/项目 |
| 私有化部署与培训 | 医院、院校、公益组织 | ¥20000 起 |

定价原则：

- 不让基础表达能力付费失效。
- AI 和云服务按成本设额度。
- 家庭价格要低，但不能指望家庭订阅单独养活项目。
- 机构和服务收入是早期更现实的现金流。
- 若通过公益或课题经费补贴，应优先补贴患者家庭使用。

## 5. 阶段计划

### 阶段 0：真实场景验证

时间：0-2 个月

目标不是收费，而是证明成人失语场景真实存在、词库方向正确、照护者愿意使用。

要完成：

- 找到 5-10 个失语/卒中照护场景反馈
- 找到 3-5 位治疗师或康复老师反馈
- 验证最刚需场景：疼痛、厕所、吃喝、睡眠、情绪、求助、选择、否定、医疗护理
- 记录图符理解问题和词图错配问题
- 形成第一版成人失语试点材料

不建议做：

- 完整账号系统
- 正式支付系统
- 大规模 AI 额度系统
- 运维团队
- 大规模患者群推广

通过标准：

- 至少 3 位专业人士认为方向值得继续
- 至少 3 个家庭/照护者愿意继续试用
- 至少 1 个真实场景证明“用图语家比纯猜测更好”

### 阶段 1：小额试点

时间：2-4 个月

目标是获得第一笔真实或准真实的资源承诺。

试点对象：

- 康复科
- 康复机构
- 医学院/康复学院课题组
- 居家康复团队
- 养老护理机构

试点包建议：

- 线上系统
- 成人失语基础词库
- 1 套机构/家庭定制板
- 1 套打印沟通册
- 1 次远程培训
- 反馈表和访谈
- 2-4 周使用复盘

收费方式：

- ¥1000-5000/3个月，或
- 免费试点但换取明确反馈、案例记录、老师背书、课题合作，或
- 作为大创/课题/公益项目的一部分获得经费

通过标准：

- 有机构愿意让真实治疗师/家属试用
- 有人愿意为定制、培训或部署付费
- 能得到可引用但匿名的反馈

### 阶段 2：服务化收入

时间：4-8 个月

目标是不用等大规模 SaaS，也能开始覆盖部分成本。

收入来源：

- 患者家庭定制沟通板
- 科室/机构模板定制
- 打印沟通册制作
- 远程培训
- 私有化部署
- AI 功能轻量额度

重点不是卖“软件许可证”，而是卖“成人失语 AAC 落地包”。

典型交付包：

| 包 | 内容 | 价格方向 |
|---|---|---|
| 家庭入门包 | 个人词库、常用场景板、打印册、一次培训 | ¥300-1500 |
| 科室试用包 | 科室模板、病区沟通板、打印材料、培训 | ¥3000-8000 |
| 机构部署包 | 私有化部署、模板库、账号、培训、支持 | ¥20000 起 |

### 阶段 3：订阅化

时间：8-12 个月

只有在试点证明有稳定需求后，再建设正式订阅。

订阅优先级：

1. 云备份和同步
2. 多照护者协作
3. AI 额度
4. 个人图片库
5. 治疗师多患者管理
6. 机构模板管理

不要先做：

- 复杂 CRM
- 大规模营销漏斗
- 多租户企业后台
- 医疗级合规承诺
- 精细计费系统

### 阶段 4：机构和公益规模化

时间：12 个月后

可能方向：

- 康复医院/科室年度服务
- 护理机构年度服务
- 残联/基金会公益采购
- 医学院课题合作
- 成人失语沟通板标准包
- 中文成人 AAC 开源生态

## 6. 获客与合作路径

### 6.1 不优先走的路径

短期不优先：

- 普通计算机社团
- 普通学生会
- 泛 AI 兴趣群
- 自闭症儿童机构作为主渠道
- 大规模患者群推广
- 没有康复场景的纯开发者招募

这些渠道不是完全没用，但转化为成人失语反馈和付费试点的效率较低。

### 6.2 优先路径

更优先：

- 失语/AAC/康复辅具论文作者
- 言语治疗师
- 康复治疗师
- 作业治疗师
- 康复科医生
- 神经内科卒中中心医生
- 康复医院或康复机构负责人
- 护理/养老康复机构负责人
- 康复治疗学、听力与言语康复学、护理学老师
- 做过患者访谈、辅具设计、康复工程课题的老师或学生

### 6.3 联系时的请求

不要一上来问“能不能合作商业化”。

更好的请求是：

- 请您判断这个方向是否真实有用
- 请您指出最重要的 3 个失语沟通场景
- 请您帮忙看一下 demo 是否有明显临床错误
- 请您介绍 1 位愿意聊 20 分钟的治疗师/家属
- 如果合适，能否做一个 2-4 周小试点

## 7. 当前最现实的第一笔钱

按概率排序：

1. 机构/科室/课题组的小额试点费
2. 患者家庭的定制沟通板和打印册服务费
3. 康复/医学相关课题、大创、社会实践经费
4. 机构部署和培训服务费
5. 家庭云服务订阅

家庭订阅不是不重要，但不应被设定为第一现金流来源。

原因：

- 失语患者家庭触达难
- 家属付费意愿需要真实使用后才会出现
- 家庭客单价低
- 支持成本不低
- 治疗师/机构背书会显著影响家庭是否愿意使用

## 8. 风险与边界

### 8.1 医疗边界

图语家当前应表述为：

- 辅助沟通工具
- 康复照护沟通支持
- 失语患者与家属沟通辅助
- 用户研究/可用性验证阶段

不应表述为：

- 治疗失语症
- 替代言语治疗
- 医疗诊断工具
- 医疗器械级康复系统
- 保证改善语言能力

### 8.2 隐私边界

成人失语场景包含医疗、家庭、护理和情绪数据。商业化前必须坚持：

- 默认本地优先
- 明确同意后才云同步
- 不售卖患者数据
- 不做未经伦理审查的数据商业化
- AI 日志和纠错记录可关闭
- 机构版要有权限和导出控制

### 8.3 AI 边界

AI 可以辅助表达，但不能替患者做医疗决策。

必须避免：

- AI 自动生成医疗建议
- AI 替代医生/治疗师判断
- AI 在患者未确认时对外发送敏感内容
- AI 把猜测当事实

建议原则：

> AI 输出永远是候选表达，最终由患者或照护者确认。

## 9. 30 天行动计划

### 第 1 周：整理试点材料

交付：

- 1 页《成人失语图语家试点说明》
- 1 页《治疗师反馈问题清单》
- 1 页《家属访谈说明》
- 线上 demo 链接
- 3 个典型场景截图：病房、居家照护、康复训练

### 第 2 周：找专业反馈

目标：

- 联系 5 位失语/AAC/康复辅具论文作者或老师
- 联系 3 位言语治疗师或康复治疗师
- 至少完成 2 次专业访谈

问题：

- 哪些场景最刚需？
- 哪些词不能少？
- 哪些图片可能误解？
- 家属最可能在哪里卡住？
- 是否适合做 2-4 周小试点？

### 第 3 周：找家庭/照护场景

目标：

- 找到 3 个失语/卒中照护者反馈
- 让至少 1 个家庭试用
- 收集真实错图、缺词、误触、不会用的问题

### 第 4 周：形成试点报价与边界

交付：

- 3 个月试点包说明
- 免费试用边界
- 小额付费报价
- 数据隐私说明
- 非医疗声明
- 试点验收指标

## 10. 是否值得继续商业化的判断标准

继续投入的信号：

- 治疗师愿意推荐给家属试用
- 家属愿意连续使用超过一周
- 患者能通过图片表达以前难以表达的需求
- 机构愿意提供试点场景
- 有人愿意为定制、培训、部署或云服务付费

暂缓商业化的信号：

- 只有技术人觉得有意思，但没有治疗师/家属愿意试
- 家属觉得“麻烦，不如猜”
- 患者无法理解核心图片
- 治疗师认为临床场景不成立
- 试点全靠人情，没人愿意承担任何资源成本

---

## 11. 当前结论

图语家最贴合实际的商业化路径是：

> 成人失语垂直场景切入，免费保留基础沟通权，通过康复/照护机构试点、词库与沟通板定制、培训部署、云同步和 AI 增强实现可持续运营。

最不应做的是：

> 在没有成人失语真实试点前，先投入大量时间建设完整账号系统、复杂订阅后台、AI 算力平台和运维团队。

下一步最重要的不是继续补功能，而是拿着一个清晰的成人失语试点包，找到真实治疗师和照护者，让他们用一次。
